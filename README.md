Face Mask Detection System

A real-time Face Mask Detection System using Deep Learning and Computer Vision. The project detects whether a person is wearing a face mask through a webcam using OpenCV and a MobileNetV2-based classifier.
Features
- Real-time face detection
- Mask/No Mask classification
- Bounding box visualization
- High accuracy

Technologies
- Python
- TensorFlow
- Keras
- OpenCV
- NumPy

Dataset
Face Mask Dataset (Kaggle)

Results
Achieved approximately 96–98% accuracy.

Future Scope
- Detect multiple safety equipment
- Improve accuracy
- Deploy on edge devices
